# 1. 项目概述

## 1.1 业务背景

### 客户与项目

**商达公用集团**（山东公用控股旗下，中国水产与流通协会设施渔业分会会长单位）战略定位「中国 RAS 未来水产引领企业」。

**千岛湖智慧鱼谷**项目：
- 总投资：约 9.73 亿
- 占地：约 619 亩
- 养殖水体：8.1 万立方米
- 年产：约 1.8 万吨
- 定位：以千岛湖地理标志「千岛湖鲢鳙」为基础，拓展淳安渔业一二三产深度融合

### 溯源诉求

建设**可验真、不可篡改、多方共治**的全鱼品溯源体系，覆盖：
- **保水渔业**（千岛湖天然有机）：生态放养、鲢鳙为核心、不投人工饲料
- **RAS 工厂化循环水养殖**：引用千岛湖深层低温水、封闭循环系统高密度可控养殖

---

## 1.2 技术选型

| 技术 | 选择理由 |
|------|----------|
| **蚂蚁链** | 国内区块链领先、浙食链早期技术承建方、客户明确要求 |
| **浙食链兼容** | 数据标准与浙江省平台及未来全国平台兼容 |
| **双模式** | 保水渔业 + RAS 两条溯源路径均可配置 |

---

## 1.3 项目范围

| 环节 | 负责方 | 说明 |
|------|--------|------|
| 种源/投放 | 本平台 | 登记上链 |
| 养殖/捕捞 | 本平台 | 双模式数据采集上链 |
| 加工/检测 | 本平台 | 批次管理、检测报告上链 |
| **储运/配送** | **蚂蚁数科** | **本平台不重复建设，通过对接获取数据** |
| 溯源查询 | 本平台 | C端扫码+链上核验 |

---

## 1.4 产品目标（可衡量）

| 目标 | 衡量方式 |
|------|----------|
| 全链路可追溯 | 各环节登记上链，支持单尾/批次追溯 |
| 数据不可篡改 | 关键操作与凭证经蚂蚁链存证 |
| 双模式覆盖 | 保水渔业与 RAS 均可配置 |
| 认证与公信 | 有机认证、地理标志数字化绑定 |
| 政府监管可视 | 大屏、报表、抽检与预警 |
| 消费者可验真 | 一键扫码查看溯源链+链上核验 |

---

## 1.5 非功能需求

| 类型 | 需求 |
|------|------|
| **性能** | 溯源查询响应 ≤ 3s；批量上链队列 + 重试 |
| **可用性** | 业务系统 ≥ 99%；链核验失败降级 |
| **安全** | HTTPS、敏感数据加密、接口鉴权 |
| **合规** | 个人信息脱敏、操作日志可审计 |
