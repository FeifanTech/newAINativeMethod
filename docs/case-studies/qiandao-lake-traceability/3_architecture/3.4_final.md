## 核心内容摘要

### 架构设计

- **分层**：应用展示层 → 接入层 → 应用层 → 平台处理层 → 外部系统
- **核心模块**：主体服务、批次服务、溯源服务、监管服务、认证服务、链适配层

### 技术选型

| 层次 | 技术 |
|------|------|
| 后端 | Spring Boot |
| 数据库 | MySQL |
| 缓存 | Redis |
| 消息队列 | Kafka |
| 区块链 | 蚂蚁链 BaaS |

### 关键设计

1. **双模式**：保水渔业 + RAS 在数据模型和接口上独立
2. **链适配层**：抽象链接口，支持多链扩展
3. **降级策略**：链核验失败时降级为「暂不展示链上核验」
4. **标准兼容**：浙食链/全国平台数据标准预留

### 非功能需求满足

| 需求 | 实现方式 |
|------|----------|
| 性能 ≤ 3s | 缓存 + 异步上链 |
| 可用性 ≥ 99% | 降级策略 + 重试机制 |
| 安全 | HTTPS + 鉴权 + 敏感数据加密 |
| 合规 | 脱敏 + 审计日志 |
