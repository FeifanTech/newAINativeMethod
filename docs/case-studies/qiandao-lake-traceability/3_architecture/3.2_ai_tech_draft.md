# 3.2 AI 技术方案草稿

> 本节展示 AI 生成的技术方案草稿。
> 
> 使用 Skill: `architecture-principles`

---

## 触发检查

AI 自动加载 `architecture-principles` Skill：

```
触发条件：用户提到架构设计、技术方案、技术选型
执行原则：
  - 遵循核心原则：简单优于复杂、边界清晰、可观测、可演进、安全合规
  - 使用产出模板：背景、目标、架构图、核心模块、接口、选型理由、风险与回滚
```

---

## AI 产出：技术方案草稿（v0.1）

```markdown
# 千岛湖全鱼品溯源平台 · 技术方案

> 版本：v0.1（草稿）

---

## 一、背景与目标

### 1.1 业务背景

- 客户：商达公用集团
- 技术选型：蚂蚁链 + 浙食链兼容
- 双模式：保水渔业 + RAS

### 1.2 技术目标

| 目标 | 说明 |
|------|------|
| 全链路可追溯 | 各环节登记上链 |
| 边界清晰 | 业务域与链对接解耦 |
| 可观测 | 上链、核验有日志 |
| 可演进 | 链配置可扩展 |

---

## 二、总体架构

### 2.1 逻辑架构

```
┌─────────────────────────────────────┐
│           应用展示层                  │
│  监管 Web  │  企业 Web  │  溯源小程序 │
└─────────────────────────────────────┘
                    │
┌─────────────────────────────────────┐
│              API 网关                │
└─────────────────────────────────────┘
                    │
┌─────────────────────────────────────┐
│              应用层                  │
│  主体服务  │  批次服务  │  溯源服务   │
└─────────────────────────────────────┘
                    │
┌─────────────────────────────────────┐
│            平台处理层                 │
│    链适配层  │  溯源码生成            │
└─────────────────────────────────────┘
                    │
┌─────────────────────────────────────┐
│              外部系统                 │
│   蚂蚁链   │  蚂蚁数科  │  浙食链     │
└─────────────────────────────────────┘
```

### 2.2 技术栈

| 层次 | 技术选型 |
|------|----------|
| 后端 | Spring Boot |
| 数据库 | MySQL |
| 缓存 | Redis |
| 区块链 | 蚂蚁链 BaaS |
| 消息队列 | Kafka |

---

## 三、核心模块

### 3.1 主体服务

- 负责养殖企业、加工企业、检测机构管理
- 与蚂蚁链节点关联

### 3.2 批次服务

- 批次号生成
- 溯源码生成与绑定
- 养殖/加工数据登记

### 3.3 溯源查询服务

- C端扫码查询
- 链上核验
- 降级处理

### 3.4 链适配层

- 抽象链接口
- 支持多链扩展

---

## 四、数据模型

### 4.1 核心实体

- Subject（主体）
- Batch（批次）
- TraceRecord（溯源记录）
- Certificate（认证）

---

## 五、接口设计

| 接口 | 说明 |
|------|------|
| POST /api/subject | 创建主体 |
| POST /api/batch | 创建批次 |
| GET /api/trace/{code} | 溯源查询 |
| POST /api/chain/verify | 链上核验 |

---

## 六、风险与回滚

| 风险 | 缓解措施 |
|------|----------|
| 链上核验慢 | 降级为「暂不展示核验」 |
| 对接失败 | 记录日志，重试机制 |
```
