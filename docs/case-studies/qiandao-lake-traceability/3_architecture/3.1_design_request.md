## 输入文档

- **PRD**：[QIANDAO_LAKE_FISHERY_TRACEABILITY_PRD.md](../../../product/QIANDAO_LAKE_FISHERY_TRACEABILITY_PRD.md)（v0.4）
- **非功能需求**：
  - 性能：溯源查询 ≤ 3s
  - 可用性：≥ 99%
  - 安全：HTTPS、接口鉴权、敏感数据加密
  - 合规：个人信息脱敏、日志可审计

---

## 关键设计约束

### 业务约束

1. **双模式**：保水渔业 + RAS 两种养殖模式在数据模型和接口上需边界清晰
2. **外部对接**：蚂蚁数科流通系统（API 对接）、蚂蚁链存证、浙食链/全国平台兼容
3. **链上核验**：关键数据需上链，但需支持降级（核验失败不影响溯源展示）

### 技术约束

1. **区块链**：蚂蚁链 BaaS 平台
2. **数据标准**：与浙食链兼容
3. **可观测**：上链、核验、关键业务操作需有日志和指标

---

## 设计目标

| 目标 | 说明 |
|------|------|
| 边界清晰 | 业务域与链对接解耦，双模式边界清晰 |
| 可观测 | 上链、核验、关键操作有日志 |
| 可演进 | 链配置可扩展、主体类型可配置 |
| 安全合规 | 鉴权、脱敏、审计 |

---

## 输出预期

技术方案应包含：
1. 总体架构图（逻辑视图）
2. 核心模块设计（主体服务、批次服务、溯源服务、链适配层）
3. 数据模型设计
4. 接口设计
5. 技术选型说明
6. 部署方案
7. 风险与回滚策略
