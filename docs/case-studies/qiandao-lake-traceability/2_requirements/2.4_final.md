## 核心内容摘要

### 背景与目标

- **客户**：商达公用集团（千岛湖智慧鱼谷）
- **项目**：千岛湖全鱼品溯源平台
- **技术选型**：蚂蚁链 + 浙食链兼容
- **覆盖范围**：养殖→加工→检测，流通环节对接

### 目标用户

| 用户角色 | 核心诉求 |
|----------|----------|
| 政府监管方 | 主体监管、检测监控、违规预警 |
| 养殖企业 | 数据上链、品牌溢价、减少重复检测 |
| 加工/检测主体 | 批次管理、检测报告上链 |
| 消费者 | 扫码溯源、链上验真 |

### 功能列表（精简版）

| 模块 | 优先级 | 说明 |
|------|--------|------|
| 主体与节点 | P0 | 政府、企业、检测机构管理 |
| 种源与投放 | P1 | 苗种登记、投放决策 |
| 养殖/捕捞 | P0 | 双模式（保水/RAS）数据采集 |
| 批次与溯源码 | P0 | 批次号、溯源码生成 |
| 加工与检测 | P0 | 加工批次、检测报告上链 |
| 流通对接 | P0 | 读取蚂蚁数科数据 |
| 认证与标签 | P1 | 有机、地理标志数字化 |
| 溯源查询 | P0 | C端扫码、链上核验 |

### 非功能需求

| 类型 | 需求 |
|------|------|
| 性能 | 溯源查询 ≤ 3s |
| 可用性 | ≥ 99%，链核验失败降级 |
| 安全 | HTTPS、敏感数据加密 |
| 合规 | 个人信息脱敏、日志可审计 |

---

## 成功指标

| 指标 | 衡量方式 |
|------|----------|
| 全链路可追溯 | 各环节登记上链，支持单尾/批次追溯 |
| 数据不可篡改 | 蚂蚁链存证，链上可验真 |
| 双模式覆盖 | 保水渔业与 RAS 均可配置 |
| 认证数字化 | 有机认证、地理标志扫码可查 |
